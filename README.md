# 期货相邻月份价差监控 (TqSdk)

为每个品种计算**相邻月份价差**，并考虑交易所的**跨期价差合约**，做三腿对比：

| 腿 | 含义 |
|----|------|
| 腿1 | 近月合约 |
| 腿2 | 远月合约 |
| 腿3 | 交易所跨期价差合约 (`DCE.SP` / `CZCE.SPD`)，方向统一为 **近月 − 远月** |

每条腿都保留 **bid/ask 的价格与数量**。输出 Excel + 自动刷新 HTML，持续盯盘。

## 关键概念

- **合成价差**：由腿1、腿2 的盘口推算的可成交价差
  - 合成买价差 = 近月卖价 − 远月买价（买近卖远的成本），量 = min(近卖量, 远买量)
  - 合成卖价差 = 近月买价 − 远月卖价（卖近买远的收入），量 = min(近买量, 远卖量)
- **组合**：交易所价差合约自身的盘口（统一翻转到 近−远 方向）
- **套利空间**（组合 vs 合成）：
  - 卖组合套利 = 组合买价 − 合成买价差（卖组合 + 买两腿，>0 有利）
  - 买组合套利 = 合成卖价差 − 组合卖价（买组合 + 卖两腿，>0 有利）
  - HTML 中正套利的行会高亮绿色

> 只有 **DCE / CZCE** 有交易所挂出的跨期价差合约，可做完整三腿；
> 上期所/能源/中金/广期没有组合合约，仅做两腿合成价差，组合相关列为空。

## 使用

1. 编辑 `config.ini`，填入快期账户 `user` / `password`。
2. 运行：

```bash
python spread_monitor.py
```

3. 打开 `output/spread_monitor.html`（浏览器内每隔几秒自动刷新），
   或 `output/spread_monitor.xlsx`。
4. `Ctrl+C` 停止。

## 配置 (`config.ini`)

| 项 | 说明 |
|----|------|
| `exchanges` | 监控的交易所 |
| `max_months` | 每品种从最近月起取几个月做相邻配对 |
| `only_adjacent` | true=仅相邻月；false=把交易所所有跨期组合也纳入 |
| `products` | 限定品种(逗号分隔)，留空=全部 |
| `refresh_seconds` | 重写文件 / 页面刷新间隔(秒) |
| `output_dir` | 输出目录 |

## 依赖

`tqsdk`、`pandas`、`openpyxl`（已确认环境中存在）。
