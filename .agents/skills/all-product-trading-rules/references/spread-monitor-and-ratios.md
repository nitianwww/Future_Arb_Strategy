# 价差监控：盘口合成、标签与比例口径

`spread_monitor.py` 的计算口径（套利筛选视图）。方向**全程统一 近月 − 远月**。
静态调试数据见 `make_static_html.py`（不连行情即可生成 `output/spread_monitor_static.html`）。

## 1. 月份标签（每腿可多标签，逗号全显示）
对每个品种在监控范围内的活跃合约分类，价差的近/远两腿各继承自己合约的标签：
- **主力**：持仓量(open_interest)最大的合约
- **近月**：最近月（month_key 最小）
- **注销月**：该合约日历月 ∈ 品种注销月集合(config delivery_month)
- **注销月后第一个月**：排序后其前一个活跃合约的日历月 ∈ 注销月集合
> 不可转抛(N)品种注销月=1–12，故其每个月都带"注销月/注销月后第一个月"（退化，正常，按转抛=Y 筛即可）。

## 2. 合成价差（由两腿盘口，吃对手价 = 可成交）
- **合成买价差**（做多价差/买近卖远的成本）= 近月**卖价(ask)** − 远月**买价(bid)**；量 = min(近卖量, 远买量)
- **合成卖价差**（做空价差/卖近买远的收入）= 近月**买价(bid)** − 远月**卖价(ask)**；量 = min(近买量, 远卖量)
- **合成最新**（参考中枢）= 近月最新 − 远月最新
恒有 `合成卖价差 ≤ 合成最新 ≤ 合成买价差`（差额=两腿各自买卖价差）。

## 3. 交易所组合（腿3，仅 DCE.SP / CZCE.SPD 有）
统一翻转到 近−远 方向：
- **组合买价** = 组合 bid1（买一：能把价差卖出的价）
- **组合卖价** = 组合 ask1（卖一：能把价差买入的价）

## 4. 合并盘口（场内合约 + 合成，取最优）
把"合成"和"交易所组合"并成一个最优盘口（**买价=买一=能卖出价差的价；卖价=卖一=能买入价差的价**）：
- **合并买价 = max(合成卖价差, 组合买价)**　（两个 bid 侧取高）
- **合并卖价 = min(合成买价差, 组合卖价)**　（两个 ask 侧取低）
- 无组合时即 合并买价=合成卖价差、合并卖价=合成买价差。
> 注意命名：合成"买价差"是 ask 侧(成本)，合成"卖价差"是 bid 侧(收入)；所以合并买价(bid)用的是合成**卖**价差。

## 5. 最新价差（clamp）
**最新价差 = 合成最新 夹在 [min(合并买卖价), max(合并买卖价)] 之间**。
正常盘口不变；当组合错价/出现套利(买价>卖价 交叉)时把最新价差夹到边界。三个比例都用这个"最新价差"做分子。

## 6. 三个比例
- **价差比例%** = 最新价差 / 近月最新价 × 100
- **仓储费比例** = 最新价差 / (−仓储费 × 30)　（仓储费取负；正向市场价差为负→比例为正）
- **转抛比例** = 最新价差 / −(资金成本 + 仓储成本 + 时间贴水)
  - 资金成本 = 1.1 × 近月价 × 资金利率%/100 × 月份差/12　（1.1 为保证金缓冲；利率输入是百分比如 6，公式里 /100）
  - 仓储成本 = 仓储费 × 30 × 月份差
  - **时间贴水** = `decay_cost(近月,远月,windows)`：持有期(近月15日→远月15日)与品种年度贴水窗口的重叠天数×日贴水；windows 配置在 all_product_config 的 `time_decay` 列。例：郑棉 CF609→CF611 重叠61天×4=244元/吨，直接把 9-11 的"假机会"(比例1.29)打回 0.6——**漏掉此项会把交易所日历贴水误判为套利空间**
  - 含义：|转抛比例|<1 价差盖不住持有到下个交割的总成本；>1 正套(买近卖远持有)有利；符号随正/反向。
  - 资金利率在 HTML 有输入框，改动**实时重算**该列（默认值 config `funding_rate`=6）。

## 7. 套利空间（组合 vs 合成）
- 卖组合套利 = 组合买价 − 合成买价差（卖组合+买两腿，>0 有利）
- 买组合套利 = 合成卖价差 − 组合卖价（买组合+卖两腿，>0 有利）
- 最优套利 = max(两者)；HTML 中 >0 的行高亮绿色。

## 8. 算例（静态数据 m2509近 − m2511远，资金利率6%）
盘口：近 bid3049/ask3051/last3050，远 bid3009/ask3011/last3010；组合(故意错价) bid50/ask41；仓储费0.5，月份差2。
```
合成买价差 = 3051−3009 = 42      合成卖价差 = 3049−3011 = 38      合成最新 = 40
合并买价 = max(38, 50) = 50      合并卖价 = min(42, 41) = 41
最新价差 = clamp(40,[41,50]) = 41
价差比例% = 41/3050×100 = 1.344
仓储费比例 = 41/(−0.5×30) = −2.733
资金成本 = 1.1×3050×0.06×2/12 = 33.55 ; 仓储成本 = 0.5×30×2 = 30
转抛比例 = 41 / −(33.55+30) = 41/−63.55 = −0.6452
卖组合套利 = 50−42 = 8 ; 买组合套利 = 38−41 = −3 ; 最优套利 = 8 (绿)
```

## 9. 输出与交互
- HTML：点列头排序、筛选(交易所/转抛/标签/品种合约/仅有组合)、资金利率输入框；状态存 localStorage，自动刷新后保留、可暂停。
- Excel：表头开自动筛选、冻结前两列。
- 数据(乘数/tick/仓储费/注销月/转抛)来自 TqSdk 实时 + `all_product_config*.xlsx`(见 config-schema / storage-fee / rollover-and-cancel-month)。
