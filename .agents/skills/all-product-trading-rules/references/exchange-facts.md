# 交易所/品种分类事实

用于快速判断转抛、注销月、套利可行性。

## 交易所跨期价差合约（套利监控用）
只有 **DCE 和 CZCE** 挂出可交易的跨期价差组合合约，可做完整三腿（近月 outright + 远月 outright + 价差合约）：
- DCE：`DCE.SP <leg1>&<leg2>`（如 `DCE.SP m2409&m2501`）
- CZCE：`CZCE.SPD <leg1>&<leg2>`（如 `CZCE.SPD CF409&CF501`）
- 只取**同品种跨期**；跨品种(`SPC`/`IPS`)和带 `F` 后缀的特殊腿剔除。
- SHFE/INE/CFFEX/GFEX 无此类组合合约 → 只能两腿合成价差。
- TqSdk 用 `query_quotes(ins_class="COMBINE", exchange_id=...)` 发现。

## 交割方式分类（决定转抛）
- **仅厂库（无仓库）**：FG 玻璃、PG 液化石油气、OP 胶版印刷纸 → 规则上算可转抛(Y)，但 OP 因12个月有效期双重保守仍 N。
- **含车(船)板**：LH 生猪、LG 原木、ZC 动力煤、PK 花生、AP 苹果、PM 普麦、RS 菜籽、WH 强麦、JD 鸡蛋 → 不可转抛(N)。
- **仓单长期有效（无强制注销）**：金属(CU/AL/ZN/PB/NI/SN/BC)、贵金属(AU/AG)、原油 SC、燃料油 FU → 可转抛、注销月空。
- **按生产/注册日计有效期(N)**：RB/WR(90天)、HC(360天)、SS(360/315天)、AO(180天)、AD(360天)、NR(报关18个月)。
- **每个交割月注销(N)**：B 豆二、P 棕榈油、RR 粳米、EB 苯乙烯、JM 焦煤、JD 鸡蛋、BZ 纯苯。
- **铂钯特殊**：仓库长期有效 + 厂库每年8月统一注销 → Y，注销月保守记 8。

## 夜盘收盘时间分类（trading_hours）
- 23:00 收：多数农产品/化工/黑色
- 25:00(次日01:00) 收：有色基本金属 CU/AL/ZN/PB/NI/SN/SS/BC/AO/AD
- 26:30(次日02:30) 收：AU 黄金、AG 白银、SC 原油
- 无夜盘：股指 IF/IC/IH/IM、国债 T/TF/TL/TS、多数老旧/农产品(AP/CJ/JD/LH/SI/LC/PS/稻麦类等)、原木 LG

## 非通用标准仓单品种（郑商所，转抛受限相关）
棉花、菜籽、动力煤、粳稻、甲醇、玻璃、白糖、硅铁、锰硅、棉纱、苹果、红枣、尿素、烧碱。

## 新品种上市时间（核对参考）
- 铸造铝合金 AD：2025年中(SHFE)；胶版印刷纸 OP：2025-10(SHFE)
- 纯苯 BZ：2025(DCE)；丙烯 PL：2025-07-22(CZCE)
- 铂 PT、钯 PD：2025-12(GFEX)

## 月份代码
- 4位 YYMM（多数所）：2501=2025年1月
- 3位 YMM（郑商所）：501=2025年1月；跨十年用到期日/expire_rest_days 排序更稳
