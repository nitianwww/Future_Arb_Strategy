# 转抛(roll_over_arbitrage) 与 仓单注销月(delivery_month)

## 判定规则（用户确认的口径）

### 是否可转抛 Y/N
"转抛" = 跨期正套时，近月接货拿到的标准仓单，能否转抛到远月继续用于交割。
**满足任一即不可转抛(N)**：
1. **每个合约月都注销**仓单（交割细则写"每个交割月份…注销"）；
2. **含车(船)板交割**（标准仓单类型含"车船板/车（船）板"）；
3. **以注册/生产日计有效期、无具体注销月份**（如"生产日起360天""注册起12个月""90天内有效"）；
4. **双重规则**（既有按月注销又有按天有效期等混合信号）→ 保守取 **N**。

**例外/特别约定**：
- **仅厂库交割（无仓库）→ 算可转抛(Y)**，备注注明"仅厂库"。（早期版本曾把仅厂库判 N，已改。）
- **国债 T/TF/TL/TS、集运 EC**：无标准仓单/现金交割 → **N**。
- **股指 IF/IC/IH/IM**：纯财务滚动，无交割约束 → **Y**。
- 金属(铜铝锌铅镍锡、国际铜)、黄金白银、原油、燃料油等仓单长期有效 → **Y**。

### 仓单注销月
- **不可转抛(N) → 注销月一律 `1-12`**（哪怕无对应合约月份也这么写）；原因写备注。
- **可转抛(Y) → 注销月 = 实际强制注销月**；长期有效(无强制注销)留空。
- 有效期挂钩生产年份 → 记**最终注销的日历月份**（棉花至N+1年11月→11、红枣→9、菜油→5、白糖→11）。
- 仓库长期有效但厂库有年度注销的（铂钯厂库8月、沥青厂库10月）→ 保守按厂库注销月记，备注说明。

### 闭环校验（必须满足）
全表 `转抛=N ⟺ 注销月=1-12`，0 违例。改完务必校验。
