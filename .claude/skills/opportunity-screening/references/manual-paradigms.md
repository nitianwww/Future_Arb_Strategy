# 人工筛选范式（用户验证口径）

来源：2026-08 用户人工筛选实盘策略的归纳。这些是**人工判断的思维范式**，与 screener 自动策略的映射关系见各节。人工案例是范式的"活教材"——调整对应 screener 策略时，先用这些案例回测口径是否还能命中。

## 范式一：同构价差段插值检验

**同构的严格定义**（`comparable` + `s_kink_repair` 代码口径，2026-08-10 核对）：
1. 月差相同；
2. **注销状态相同**——`cancel_state` 四态(both/near/far/none)必须一致，不是"都不含注销月"那么粗；
3. 区间**严格内部**（不含两端腿）跨注销月数相同（`cancels_between`）；
4. 做 (A+C)/2 插值估值还需**近月等距**。

**逻辑**：同构三段 A/B/C 应平滑过渡。B 为局部极值（折角）时，理论B=(A+C)/2，偏差即错价，做回归。

- 案例（JM10-11 正套，2026-08）：JM9-10≈10、JM11-12≈5，但 JM10-11≈0。理论 10-11≈7.5，低估 → 做多。**同构成立的真正原因**：JM 是每月注销品种（注销月1-12），三段 cancel_state 统一为 "both"、跨注销数均 0，注销维度天然均匀——每月注销品种的相邻段互为同构，插值可放心用（但这类品种不可转抛）。
- ⚠️ JM 有 `REGIME_BREAKS` 202701（交割标准提高）：段链若延伸到 2612-2701 即跨断层，不可再比。
- **对应 screener**：`s_kink_repair` / `s_main_kink` / `s_matched_pair`。

## 范式一b：非同构相邻段的结构性不等式（back 单调 + 注销不对称）

**逻辑**：两段**不同构**时不能插值，但可以有方向性的结构不等式。back 结构给基线（逐月价差递减 → 前段应≥后段）；若中间腿是注销月，注销折价给**同向修正**（中间腿折价 → 前段更宽、后段更窄）。两个理由同向时，不等式未兑现即是机会，目标"至少持平"是保守下限。

- 案例（I 蝶式，2026-08）：多 2701-2703 + 空 2703-2705（=多01空2×03多05）。**注意 1-3 与 3-5 不是同构**——铁矿注销月 3,9，1-3 的 cancel_state="far"、3-5 是 "near"，`comparable` 判不可直接对比。交易依据不是插值，而是：back 递减 + 03 注销折价 → 1-3 理应 > 3-5，入场时未体现。
- **对应 screener**：本质是 `s_cancel_discount` 型（"中间为注销月、前后非注销 → 前段>后段"的月差-2版本），不是 `s_kink_repair`。
- **判别要点**：拿到两段先过一遍同构四条件——同构 → 插值定量估值（范式一）；不同构但注销/结构给出同向不等式 → 定性方向交易（本范式），不要错用插值给目标价。

## 范式二：仓单注销月近月折价压力（+流动性替代表达）

**逻辑**：高仓单 + 临近注销月 → 注销月合约承压，注销月−注销后月价差理应很负。历史同等仓单下若当前未体现，做空该段价差。若理论最优的合约对没有成交量，**用流动性好的合约对替代表达**（方向暴露一致即可）。

- 案例 A（J 1-5 反套，2026-08）：J 9-1 为负、仓单很高、3 月注销 → 3-4 理应很负但未体现。3/4 月无成交量 → 用 1-5 做空替代。
- 案例 B（Y 11-12/11-1 反套，2026-08）：9-11 已很负，11 月是豆油注销月，11 理应对后折价 → 做空 11-12 或 11-1。
- **对应 screener**：`s_cancel_discount` / `s_cancel_collapse`（注销段口径=注销月−注销后月）。流动性替代表达目前是人工层操作，screener 的 `LIQ_MIN_OI` 只做钓鱼桶降级，不会自动换腿。

## 范式三：近端高价差向远期递延 + 换月时机

**逻辑**：近端价差高企（如 9-1 很高）且基本面稳定时，价差结构会随时间向远月对递延传导（1-5 会涨向 9-1 曾经的位置）。主力换月（9 月：09→01）是催化剂，换月前后入场时机最好。

- 案例 A（TA 1-5 正套，✅ 已验证）：TA9-1 很高，TA1-5 在 0 附近做多，9 月换月催化，涨到 ~100 止盈，约 100 点利润。
- 案例 B（V2701-2705 正套，进行中）：1-5 接近历史全期最低，8 月入场时间充裕，9 月换月可能引发波动。历史区间约 -300~-240。
- **对应 screener**：`s_deferral`。换月时点目前靠人工把握（`s_liq_premium` 有主力换月进度可参考）。

## 范式四：历史极值 + 剩余时间充裕 → 刷波动

**逻辑**：价差到历史全期极值附近，且距到期还有数月（有换月等波动催化在前方），即使基本面（如仓单高位）不利，也可以做区间刷波动而非单边持有——极值位置提供安全边际，时间提供波动机会。

- 案例（V2701-2705，2026-08）：1-5 历史最低附近入场，仓单虽高但才 8 月，区间 -300~-240 有 60 点刷波动空间。
- **对应 screener**：`s_stat_arb` 分位极值触发后，人工层判断"剩余时间是否充裕、前方有无催化"决定单边持有还是刷波动。

## 落地决策（2026-08-12 用户拍板，已实现进 screener.py）

1. **同构判断放松**：不再要求注销状态完全一致，以同构为基准——非同构时注销偏置 E（`_cancel_bias`：仅远腿注销+1、仅近腿注销−1）与信号方向同向（真实结构比同构更有利，插值/零基准为保守下限）才输出；反向或中性不输出；**跨注销数仍须相同**（断链只解释偏离、方向不定）。落地：`s_kink_repair`、`s_matched_pair`（分组键去掉注销状态）、`s_deferral` 新增泛化蝶式非同构分支（共中腿+等月差，不限连续挂牌月，覆盖 I 1-3 vs 3-5 型）。
2. **范式二做空不设临近窗口**：`s_cancel_collapse` 做空分支去掉 days≤near_days —— 错价现在就存在，J（距注销200天）/Y（80天）提前做空可触发。做多分支天数条件不变。
3. **范式四进统计策略**：`s_stat_arb` 新增"远期同期极值"分支——前腿到期>far_days(120) + 同期分位≤10或≥90（样本≥5年）即输出，**免顺季节性与结构过滤两道硬筛**，标注"刷波动候选"。far_days 取 120 而非远期口径 180，因动机案例 V2701 仅约 155 天。
4. **换月催化横切标注：暂不做**（用户明确先不考虑）。
5. **规则断层方向裁决**：跨断层机会不再一律排除——新标准腿（≥断层月）**净暴露为多**则保留并标注（独立考量因素），净暴露为空则直接剔除（`_break_verdict`）。JM2701 只做多头腿。

## 通用提醒

- 旺季高价属季节性正常，勿当错价（详见 all-product-trading-rules skill 的 seasonality.md）。
- 同构判定务必走全四条件（见范式一），最易漏的是 cancel_state 四态一致——"区间都不跨注销月"不够，两端腿本身是否注销月也必须一致（I 的 1-3 vs 3-5 即反例）。
- 仓单分位只是弱佐证不是信号（系统化已证伪），但在范式二里作为方向背书是核心条件——区别在于范式二还叠加了注销月时点结构。
